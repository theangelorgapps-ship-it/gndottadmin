# GoodNews Halobox Admin

## Product

GoodNews Halobox Admin is the operational control center for a Christian streaming service. Administrators manage Sermons, Shows, Teachings, Videos, Live TV, Personalities, Locations, subscriptions, users, media, and system configuration. The product must make frequent content work fast and dependable on desktop and mobile.

## Users and priorities

- Content editors need clear forms, dependable uploads, safe destructive actions, and fast search.
- Administrators need dense but readable operational data, responsive settings, and visible save feedback.
- Mobile users need the same workflows without page-level horizontal scrolling or desktop-only controls.

## Brand personality

Calm, trustworthy, purposeful, and contemporary. GoodNews Halobox uses deep navy surfaces, clear blue accents, compact sans-serif typography, and subtle hierarchy. The interface should feel like a professional publishing tool, not a promotional landing page.

## Design principles

1. Preserve every existing workflow, route, database field, and integration while improving presentation.
2. Use the public vocabulary: Sermons, Shows, Teachings, Videos, Personalities, and Locations.
3. Put primary actions and record status where they are easy to find; keep secondary information quiet.
4. Structure responsiveness rather than shrinking desktop screens: navigation becomes a drawer, grids collapse, forms stack, and tables scroll locally.
5. Make keyboard focus, labels, dialog naming, toggle state, errors, and busy states explicit.
6. Respect reduced motion and use animation only to clarify state changes.

## Anti-references

- Legacy Streamit naming and red entertainment branding.
- Visible IMDb references, ratings, stars, or review-oriented presentation.
- Oversized headings, decorative gradients, glass on every panel, unnecessary pills, and excessive motion.
- Horizontal page overflow, clipped menus, unreachable mobile actions, and unlabeled icon controls.
